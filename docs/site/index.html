File manager for macOS

A file manager with superpowers. Made for the Mac.

Split view, a terminal that follows the folder you're in, tabs and panels, in a fast native app that also speaks Finder: tags, Quick Look, iCloud and your keyboard shortcuts. Inspired by KDE Dolphin.

Everything you need, nothing in the way.

The tools power users reach for every day, in a native app that feels at home on your Mac.

Split view and tabs

Two folders side by side with animated split, copy or move between panes, and as many tabs as you like. Your session comes back next time.

A terminal that follows you

Press F4 for your own shell right under the files. Change folder in the view and the terminal follows; cd in the terminal and the view follows.

Panels

Places with foldable sections, a Folders tree, and an Information panel with big previews and an inline player.

Speaks Finder

Tags, aliases, Quick Look, Get Info, Services, AirDrop, iCloud status and Finder's shortcuts.

Remote folders

SFTP, FTP, SMB, WebDAV and Android phones, browsed like local folders.

An app library

Applications opens as big icons with an instant, animated search. Delete apps with ⌘⌫ or the Dock's Trash, or drop one from a disk image to install it.

Previews of everything

Thumbnails for images, documents and every video format (MKV, WebM, AVI…), with smooth zoom from tiny icons to big previews.

Safe with your files

Undo for file operations, a conflict dialog that never overwrites silently, and the Trash with put-back and Finder's sounds. Set it up once and it never nags you with password prompts.

Always up to date

Porpoise checks for new versions once a day (you choose) and updates itself in one click, keeping all your settings and permissions.

Install in a minute.

Everything Porpoise needs is inside the app. Nothing else to install.

Drag to Applications

Download Porpoise.dmg, open it and drag Porpoise onto the Applications folder.

Allow it once

Porpoise is free and isn't signed through Apple's paid program, so macOS asks the first time. Open System Settings › Privacy & Security and click Open Anyway.

Give it access

Porpoise's welcome window walks you through its permissions, with Touch ID where macOS asks. Once, then it never asks again, just like Finder.

Requires macOS 15 Sequoia or newer on Apple Silicon. Porpoise updates itself: when a new version is out, one click installs it and relaunches.
