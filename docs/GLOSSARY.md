# Product terms

| Term | Meaning |
| --- | --- |
| Transfers | The compact nonmodal progress window, opened through Window → Transfers (⌥⌘J). |
| Operation | One copy, move or other filesystem job; an operation can contain many files and folders. |
| Processed | Entries resolved so far, including skipped or reused entries. It does not imply all were newly copied or created. |
| Details | Expands measured speed history within the operation card, without displaying a per-file queue. |
| Speed history | The current operation’s measured throughput over time. It is not a list of past transfers or pending files. |
| Recovery record | Internal operation state retained for safe recovery or Undo; not a past-transfer history view. |
| Custom Tool Output | The separate window for custom command output and status. It does not keep Transfers open. |
