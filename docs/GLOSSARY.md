# Product terms

| Term | Meaning |
| --- | --- |
| Transfers | The compact nonmodal progress window, opened through Window → Transfers (⌥⌘J). |
| Operation | One copy, move or other filesystem job; an operation can contain many files and folders. |
| Processed | Entries resolved so far, including skipped or reused entries. It does not imply all were newly copied or created. |
| Show Speed | Expands measured speed history within the operation card, without displaying a per-file queue. |
| History | Searchable summaries of previous operations. |
| Tools | Custom command output and status, available from the Transfers window. |
